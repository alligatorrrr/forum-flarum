# Badge Shop 徽章商店

![License](https://img.shields.io/badge/license-MIT-blue.svg) 

一个Flarum扩展。允许用户购买徽章。  


### Installation

Install with composer:

```sh
composer require ziiven/ziven-badge-shop:*@dev
```

### Updating

```sh
composer update ziiven/ziven-badge-shop:*@dev
php flarum migrate
php flarum cache:clear
```
